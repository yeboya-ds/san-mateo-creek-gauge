# San Mateo Creek Gauges

Local Vite + React dashboard for monitoring key creek gauges, a reservoir, and San Francisco Bay tide levels relevant to winter flooding in San Mateo County.

## Status

Prototype. Data is provisional and not for official emergency decisions.

## Sites

1. Pescadero Creek near Pescadero — action 10 ft
2. Pescadero Creek at Stage Road — MONITOR
3. Belmont Creek — action 4.1 ft
4. Colma Creek at Orange Memorial Park — action 6.75 ft
5. San Francisquito Creek at Stanford — action 11 ft
6. Pilarcitos Creek above Stone Dam — MONITOR
7. Lower Crystal Springs Reservoir at Dam — MONITOR (elevation)
8. San Francisco tide — action 1.2 ft MHHW
